# Production Manager

## Purpose

Accountable for production processes and batch release readiness.

## Responsibilities

- Owner of [[SOP-PROD-001]] (draft) and [[WI-PROD-003]].
- Ensuring operators follow approved work instructions.
- Escalating nonconformities found during production.

## Authority

May release a batch only after the QA sign-off defined in [[SOP-PROD-001]].

- [[WI-PROD-003]]
- [[SOP-QA-001]]
