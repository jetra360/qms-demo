# CAPA

Corrective and preventive action. A CAPA is not closed until `verified_by` and `closed_on` are set by a human.

## Problem statement

What happened, where, and how it was detected.

## Root cause

The underlying cause, not the symptom.

## Corrective action

The action taken to remove the cause.

## Verification

How we proved the action worked. Only a human fills this in.
