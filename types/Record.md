# Record

Evidence that a procedure was actually followed. Without Records, the QMS is only paperwork.

## What was done

Short factual description. No interpretation.

## Evidence

Point to the signed form, log, photo or system export.

## Result

Pass / fail / observation, plus who reviewed it.

## Traceability

Which SOP or WorkInstruction does this record prove? Link it with `related_to`.
